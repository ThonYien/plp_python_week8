 Thon Yien's Python Toolkit

About
This is my PLP Python Week 8 project. It contains three simple Python tools designed to practise basic programming skills.

 Tools Included

1. Number Guessing Game: Guess a secret number between 1 and 10.
2. To-Do List: Add, view, and remove tasks.
3. Simple Calculator: Perform addition, subtraction, multiplication, and division.

 Requirements
- Python 3
- Visual Studio Code (optional)

How to Run

Open your terminal and run:

```bash
python "toolkit(1).py"
```
